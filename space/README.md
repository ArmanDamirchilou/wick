A hosted preview of [wick](https://github.com/armandamirchilou/wick), a
command-line assistant that answers questions about a local PDF with no
internet connection.

The Space runs the published `wick-offline` package unmodified, so what you see
here is what you get after `pip install wick-offline`. The difference is where
the model runs: here it's on a shared CPU, and on your own machine it's yours.
